# 🐚 FreeCodeCamp Bash Scripting Workshop

## Build Five Programs

A collection of Bash programs created as part of the **FreeCodeCamp Relational Databases** course.

> Learn more terminal commands and how to use them within Bash scripts by creating five small programs.

## 📂 Programs

- `questionnaire.sh` — asks the user a few questions, stores the answers, and prints a personalized response.
- `countdown.sh` — accepts a positive integer as an argument and counts down to zero with a one-second delay.
- `bingo.sh` — generates a random Bingo number from 1–75 and assigns it to the correct B, I, N, G, or O range.
- `fortune.sh` — asks for a yes/no question, checks that it ends with `?`, and returns a random response.
- `five.sh` — runs the other four Bash programs consecutively.
